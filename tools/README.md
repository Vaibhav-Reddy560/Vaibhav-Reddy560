# Asset generators

Everything in `../assets/` is generated by these scripts. Run them from the repository root:

```sh
python3 tools/build_assets.py   # hero pair, ticker, divider, section plates, footer
python3 tools/build_stats.py    # the two telemetry panels
```

Requires `fontTools` (`pip install fonttools`) for the headline only.

## Regenerating the telemetry panels

The panels are a **snapshot**, not a live feed. They do not update on their own — the usual
third-party stat-card services were returning 503 and 402, which renders as a broken image, so the
numbers are measured once and committed. To refresh them, update the two inputs and re-run
`build_stats.py`:

- `LANGS` in `build_stats.py` — byte totals per language, summed across repositories:

  ```sh
  gh api repos/Vaibhav-Reddy560/<repo>/languages
  ```

  Totals span private repositories too, which is why the panels say so; using public repos alone
  drops most of the Python.

- `contrib.json` — the contribution calendar:

  ```sh
  gh api graphql -f query='
    query { user(login: "Vaibhav-Reddy560") { contributionsCollection {
      contributionCalendar { totalContributions weeks { contributionDays { date contributionCount } } }
    } } }' > tools/contrib.json
  ```

Then update the `alt` text on both `<img>` tags in the root `README.md`, since it repeats the
figures for screen readers.

## The headline

`glyphs.py` extracts `VAIBHAV` and `REDDY` from Octavus Black as SVG path outlines into
`glyphs.json`, which `build_assets.py` embeds in the hero. This is necessary because an SVG loaded
as an image runs under `default-src 'none'` and cannot fetch a font over the network — live text
would fall back to a system face.

It also records each word's **true ink bbox**, and every bit of headline geometry in
`build_assets.py` is derived from that rather than from advance widths. This matters: Octavus
Black is steeply slanted, so a word's outline overhangs its own advance box by about a third of an
em. The reveal mask's final resting position *is* the permanent crop, so a mask sized to the
advance width silently guillotines the last letter of each line — which it did, for several
commits, in a way that looks exactly like a rendering glitch. If you change the headline, re-run
`glyphs.py`; do not hand-tune padding constants to compensate.

The font itself is deliberately **not** committed here; point `OCTAVUS_TTF` at it if the default
path is wrong:

```sh
OCTAVUS_TTF=/path/to/Octavus-Black-FFP.ttf python3 tools/glyphs.py
```

`glyphs.json` only needs regenerating if the name or its size changes.

## Why the animation is CSS and not SMIL

SMIL cannot be switched off by a media query. Every animation here is CSS, and each animated
property keeps its **final** state as the base value with the keyframes running from the initial
state — so under `prefers-reduced-motion: reduce` the artwork lands on its finished frame rather
than an empty one.
